Đưa Ứng Dụng Lên Mạng (Vercel, Netlify & Go-Live)

Từ máy cá nhân ra thế giới: Hướng dẫn chi tiết cách xuất bản web bằng Netlify Drop, Vercel, trỏ tên miền riêng và nghiệm thu bàn giao.

Mục tiêu chương: Làm chủ 3 cách xuất bản ứng dụng lên mạng miễn phí (Netlify Drop kéo-thả trong 30 giây, Vercel tự động hóa CI/CD qua GitHub, và GitHub Pages); biết cách đổi tên miền phụ, gắn tên miền riêng và thực hiện bảng kiểm tra 10 điểm trước khi bàn giao.

1. Cách 1: Xuất bản siêu tốc bằng Netlify Drop (Kéo - Thả trong 30 giây)

Đây là cách đơn giản nhất dành cho người làm Vibe Coding: không cần cài đặt phần mềm, không cần dùng dòng lệnh Git mà vẫn có ngay trang web chạy online với đường dẫn HTTPS an toàn.

4 BƯỚC THỰC HIỆN VỚI NETLIFY DROP
Bước 1: Mở trình duyệt và truy cập vào địa chỉ: https://app.netlify.com/drop
Bước 2: Mở thư mục dự án trên máy tính của bạn (thư mục chứa file index.html cùng các file css, js).
Bước 3: Dùng chuột KÉO TOÀN BỘ THƯ MỤC ĐÓ VÀ THẢ vào ô chấm nét đứt trên màn hình Netlify.
Bước 4: Chờ khoảng 10-15 giây để hệ thống tải lên. Netlify sẽ cấp ngay một đường link trực tiếp (ví dụ: https://happy-curie-123456.netlify.app).
Mẹo đổi tên miền phụ đẹp mắt trên Netlify:
Sau khi tải lên thành công, bấm vào mục Site configuration → Chọn Change site name → Gõ tên bạn muốn (ví dụ: so-tay-sinh-vien) → Bấm Save. Đường link của bạn sẽ đổi thành https://so-tay-sinh-vien.netlify.app hoàn toàn miễn phí!

2. Cách 2: Triển khai tự động chuẩn doanh nghiệp với Vercel

Vercel là nền tảng điện toán đám mây hàng đầu thế giới dành cho ứng dụng web. Khi kết nối với GitHub, mỗi lần bạn sửa mã nguồn và lưu lại, Vercel sẽ tự động cập nhật trang web sau 30 giây.

4 BƯỚC TRIỂN KHAI VỚI VERCEL
Bước 1: Đẩy toàn bộ mã nguồn của bạn lên một kho lưu trữ (Repository) trên GitHub.
Bước 2: Mở trang https://vercel.com → Đăng nhập bằng tài khoản GitHub (Continue with GitHub).
Bước 3: Tại bảng điều khiển Vercel, nhấp vào nút "Add New..." ở góc trên bên phải → Chọn "Project" → Nhấn "Import" cạnh kho GitHub vừa tạo.
Bước 4: Tại màn hình cấu hình:
  - Project Name: Đặt tên cho ứng dụng của bạn.
  - Framework Preset: Nếu là HTML/CSS/JS thuần, chọn "Other".
  - Environment Variables: Thêm các khóa bí mật nếu dự án có dùng API ngoài.
  - Nhấn nút "Deploy" màu xanh.

Sau khoảng 20-30 giây, màn hình bắn pháo hoa xuất hiện và bạn nhận được đường dẫn dạng https://ten-du-an.vercel.app có tốc độ tải siêu nhanh trên toàn cầu.

3. Cách 3: Xuất bản miễn phí trọn đời bằng GitHub Pages

Nếu bạn đã lưu trữ mã nguồn trên GitHub, bạn có thể bật tính năng GitHub Pages tích hợp sẵn:

  1. Mở trang GitHub repository của bạn trên trình duyệt → Chọn thẻ Settings (Cài đặt) ở thanh menu trên cùng.
  2. Tại menu bên trái, chọn mục Pages.
  3. Ở phần Build and deployment → Mục Branch, chọn nhánh main (hoặc master) và chọn thư mục /(root) → Nhấn Save.
  4. Chờ 1-2 phút rồi làm mới trang, GitHub sẽ cung cấp link công khai dạng: https://<ten-tai-khoan>.github.io/<ten-repo>/.

4. Cấu hình tên miền riêng (Custom Domain)

Để gắn tên miền của cơ quan hay thương hiệu của bạn (ví dụ: ungdung.bvchoray.vn hoặc app.cuaban.com), vào trang quản lý DNS của nhà cung cấp tên miền và thêm các bản ghi sau:

BẢN GHI DNS MẪU TRỎ VỀ VERCEL / NETLIFY
Loại bản ghi    Tên máy chủ (Host)      Giá trị đích (Value / Points to)       TTL
CNAME           app                     cname.vercel-dns.com.                 Tự động
CNAME           web                     ten-site-cua-ban.netlify.app.         Tự động
A               @                       76.76.21.21 (Vercel IP)               Tự động

5. Bảng kiểm tra 10 điểm Go-Live bắt buộc trước khi bàn giao

CHECKLIST GO-LIVE CUỐI CÙNG:
  1. [ ] Console sạch: Mở F12 không còn dòng lỗi đỏ nào (`Uncaught Error`).
  2. [ ] Bảo vệ bí mật: Không có bất kỳ mật khẩu hay API Key thật nào bị lộ trong file mã nguồn.
  3. [ ] Thử nghiệm F5: Tải lại trang trên link online xem dữ liệu nhập vào có còn nguyên không.
  4. [ ] Kiểm tra trên điện thoại di động: Dùng điện thoại thật mở đường link web xem có bị tràn viền hay nút bấm khó bấm không.
  5. [ ] Kiểm tra liên kết: Bấm thử tất cả các nút và menu xem có trang nào bị lỗi 404 không.
  6. [ ] Chứng chỉ HTTPS: Đảm bảo thanh địa chỉ trình duyệt hiện biểu tượng ổ khóa an toàn.
  7. [ ] Thông báo người dùng: Khi gửi form thành công hoặc có lỗi, luôn hiện thông báo Toast rõ ràng.
  8. [ ] Tiêu đề & Biểu tượng: Đã đặt thẻ <title> tiếng Việt rõ nghĩa và gắn icon (Favicon).
  9. [ ] Dữ liệu mẫu: Đã dọn dẹp các dữ liệu nháp thử nghiệm không cần thiết.
  10. [ ] Tài liệu hướng dẫn: Đã viết file README.md hoặc hướng dẫn ngắn gọn cho người tiếp nhận sử dụng.
