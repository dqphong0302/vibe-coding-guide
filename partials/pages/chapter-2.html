1. Bốn tầng cấu tạo của một ứng dụng Web hiện đại

Mọi hệ thống phần mềm web dù đơn giản hay phức tạp đều được xây dựng dựa trên 4 tầng nền tảng:

  • Tầng 1: Frontend (Client-side): Chạy trên trình duyệt của người dùng (Chrome, Safari). Bao gồm HTML (khung xương), CSS (định dạng thị giác) và JavaScript (hành vi tương tác). Quy tắc vàng: Frontend là môi trường công khai, tuyệt đối không bao giờ chứa mật khẩu hoặc API Key bí mật.
  • Tầng 2: Backend & API (Server-side): Chạy trên máy chủ từ xa (Node.js, Python FastAPI, Go, hoặc Serverless Functions). Nhiệm vụ: Xác minh danh tính người dùng, kiểm tra quyền hạn (Authorization), thực hiện nghiệp vụ tính toán và giao tiếp với CSDL.
  • Tầng 3: Database (Cơ sở dữ liệu): Nơi lưu trữ dữ liệu bền vững (Persistent Data) theo cấu trúc bảng (Relational SQL) hoặc tài liệu (NoSQL). CSDL đảm bảo dữ liệu không bị mất khi người dùng tắt trình duyệt hoặc máy chủ khởi động lại.
  • Tầng 4: Infrastructure & Hosting (Hạ tầng mạng): Máy chủ đám mây, mạng phân phối nội dung (CDN), tên miền (DNS) và chứng chỉ bảo mật HTTPS (Vercel, Netlify, Cloudflare, AWS).

2. Phân tích 5 cấp độ lưu trữ dữ liệu trong thực tế

Tùy theo giai đoạn thử nghiệm hay triển khai chính thức, bạn sẽ yêu cầu AI Coding Agent lựa chọn đường đi dữ liệu phù hợp:

  1. Level 1 - Memory State (Bộ nhớ tạm JS): Dữ liệu chỉ nằm trong biến JavaScript (mất ngay khi người dùng nhấn F5 tải lại trang). Thích hợp cho hoạt ảnh giao diện và form nhiều bước trước khi submit.
  2. Level 2 - LocalStorage / IndexedDB: Lưu trực tiếp trên trình duyệt cá nhân của từng thiết bị. Không cần máy chủ, không tốn phí, xây dựng xong trong 5 phút. Rất phù hợp cho ứng dụng ghi chú cá nhân, mockup demo hoặc lưu cài đặt giao diện (Dark Mode).
  3. Level 3 - Mock JSON File: Đọc dữ liệu từ file tĩnh data.json. Rất tiện lợi cho việc kiểm tra giao diện với 30-50 bản ghi mẫu trước khi kết nối CSDL thật.
  4. Level 4 - SQLite Local Database: CSDL quan hệ lưu trong 1 file đơn duy nhất trên máy tính hoặc server. Siêu nhẹ, hỗ trợ đầy đủ cú pháp SQL tiêu chuẩn, không cần cài đặt dịch vụ CSDL phức tạp. Thích hợp cho app nội bộ máy tính và công cụ nội bộ.
  5. Level 5 - Cloud Database (Supabase / PostgreSQL): CSDL quan hệ đám mây hoàn chỉnh, hỗ trợ hàng triệu người dùng, xác thực tài khoản, phân quyền Row-Level Security (RLS) và sao lưu tự động. Đây là lựa chọn bắt buộc cho sản phẩm thương mại.

3. Cách dữ liệu di chuyển: REST API, JSON và HTTP Methods

Khi người dùng thực hiện một thao tác trên giao diện (ví dụ: bấm nút "Lưu đơn hàng"), một luồng dữ liệu chuẩn sẽ diễn ra:

LUỒNG GIAO TIẾP HTTP CHUẨN
[Client Frontend] --(1) Gửi HTTP POST + Body JSON--> [Backend API Server]
                                                            |
                                                   (2) Kiểm tra Token / Quyền
                                                   (3) Validate dữ liệu
                                                            |
                                                   (4) Ghi vào [Database]
                                                            |
[Client Frontend] <--(5) Nhận HTTP 200 OK + JSON kết quả--- [Backend API Server]

Các phương thức HTTP tiêu chuẩn bạn cần biết khi giao tiếp với AI:

  • GET /api/items: Lấy danh sách bản ghi (không làm thay đổi dữ liệu).
  • POST /api/items: Tạo mới một bản ghi.
  • PUT / PATCH /api/items/123: Cập nhật thông tin bản ghi số 123.
  • DELETE /api/items/123: Xóa bản ghi số 123.
