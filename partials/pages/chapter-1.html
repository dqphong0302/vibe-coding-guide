Bản Chất Vibe Coding & Tư Duy Làm Chủ AI Coding Agent

Tốc độ nằm ở vòng phản hồi ngắn và kỷ luật giao việc, không nằm ở việc bấm nút vô thức hay phó mặc cho AI đoán mò.

Mục tiêu chương: Làm rõ sự chuyển dịch từ gợi ý mã nguồn (Autocomplete) sang AI Agent tự chủ; nắm vững vòng lặp 4 bước Vibe Coding chuẩn mực; hiểu rõ 5 khái niệm cốt lõi (Workspace, Session, Model, Context Window, Quota) và loại bỏ tư duy code mò.

1. Sự tiến hóa từ AI gợi ý code đến AI Agent tự chủ

Lịch sử ứng dụng trí tuệ nhân tạo vào lập trình đã trải qua 3 thế hệ phát triển then chốt:

  • Thế hệ 1 - Auto-complete (Gợi ý dòng lệnh): Đại diện là GitHub Copilot đời đầu (2021-2023). AI chỉ đóng vai trò là "Tab Completion", đoán dòng lệnh tiếp theo dựa trên vài dòng code trước đó. Lập trình viên vẫn phải tự tạo file, tự sửa lỗi và tự kiểm thử.
  • Thế hệ 2 - Chat Sidebar (Hỏi đáp bên lề): Xuất hiện qua ChatGPT, Claude web và plugin sidebar (2023-2024). Lập trình viên copy-paste code qua lại giữa trình duyệt và IDE. Quá trình này tiêu tốn nhiều thời gian và thường xuyên làm mất ngữ cảnh.
  • Thế hệ 3 - Autonomous AI Coding Agent (Trợ lý tự chủ): Đại diện bởi Google Antigravity, OpenAI Codex, Claude Desktop / Claude Code (2025-2026). AI có khả năng đọc toàn bộ cây thư mục dự án, tự đề xuất kế hoạch sửa đổi nhiều file đồng thời, tự thực thi lệnh trong terminal, mở trình duyệt để kiểm thử và báo cáo kết quả qua diff trực quan.

2. Bản chất thực sự của Vibe Coding

Thuật ngữ Vibe Coding được khởi xướng bởi Andrej Karpathy (cựu Giám đốc AI Tesla, đồng sáng lập OpenAI). Nó mô tả trạng thái lập trình viên diễn đạt mong muốn bằng ngôn ngữ tự nhiên, để AI đảm nhiệm việc hiện thực hóa mã nguồn.

Tuy nhiên, Vibe Coding không phải là code mò vô định. Nếu không có đặc tả, AI sẽ tự bịa logic (hallucination), tạo ra mã nguồn rác, vi phạm bảo mật và làm tràn bộ nhớ ngữ cảnh (Context Window). Vibe Coding chuyên nghiệp là kỹ năng của một Tổng chỉ huy kỹ thuật: đưa ra yêu cầu chính xác, xét duyệt kế hoạch trước khi chạy và nghiệm thu sản phẩm qua từng bài test.

3. Năm khái niệm cốt lõi của mọi AI Coding Agent

Dù sử dụng Antigravity, Codex hay Claude Desktop, bạn bắt buộc phải hiểu 5 thực thể sau:

  1. Project / Workspace: Thư mục gốc chứa toàn bộ mã nguồn, tài liệu và cấu hình của dự án. Agent chỉ có thể thao tác an toàn bên trong phạm vi thư mục này.
  2. Session (Phiên làm việc): Cuộc hội thoại độc lập giữa bạn và AI. Khi đổi nhiệm vụ lớn, nên tạo session mới để làm sạch Context Window.
  3. Model (Mô hình suy luận): Bộ não xử lý (ví dụ: Claude 3.7 Sonnet, GPT-4o, Gemini 2.5 Pro). Mỗi mô hình có thế mạnh riêng về logic, tốc độ hoặc phân tích hình ảnh.
  4. Context Window & Token Budget: Dung lượng bộ nhớ của phiên làm việc. Càng nhiều tin nhắn cũ, bộ nhớ càng đầy, AI càng dễ bị "lú lẫn" và phản hồi chậm hơn.
  5. Quota & Rate Limit: Hạn mức sử dụng của tài khoản (tính theo số lượt gọi mỗi phút/giờ hoặc số token tiêu thụ trong ngày).

4. Vòng lặp 4 bước Vibe Coding chuẩn mực

Để đạt hiệu quả cao nhất và tránh lỗi phá hỏng mã nguồn cũ, hãy luôn tuân thủ vòng lặp 4 bước khép kín:

  • Bước 1 - Explore (Khám phá): Yêu cầu AI đọc repo, quét các file liên quan để hiểu hiện trạng mà không sửa mã.
  • Bước 2 - Plan (Lập kế hoạch): AI tạo tài liệu kế hoạch liệt kê danh sách file cần sửa, kiến trúc và rủi ro kỹ thuật; bạn duyệt trước khi chạy.
  • Bước 3 - Code (Viết mã từng phần): AI chỉ sửa đúng phạm vi đã duyệt, ưu tiên các lát cắt nhỏ độc lập (incremental slice).
  • Bước 4 - Verify (Kiểm chứng & Commit): Chạy unit test, mở trình duyệt kiểm tra giao diện, đối chiếu tiêu chí hoàn thành rồi commit git.

5. Năm cạm bẫy "Code mò" (Vibe Blindness) thường gặp

NHỮNG SAI LẦM PHỔ BIẾN CẦN TRÁNH:
  1. Prompt quá chung chung: "Làm cho tôi một web bán hàng giống Shopee." → AI sẽ tự bịa hàng trăm dòng code thừa thãi không chạy được.
  2. Không đọc Diff trước khi Apply: Chấp nhận toàn bộ thay đổi mà không kiểm tra xem AI có xóa nhầm code cũ hay không.
  3. Dồn toàn bộ tính năng vào một Prompt: Yêu cầu vừa làm giao diện, vừa làm backend, vừa làm thanh toán trong một lần bấm nút.
  4. Giữ một Session quá dài: Chat hàng trăm tin nhắn trong một session khiến context bị loãng, chi phí token tăng vọt.
  5. Bỏ qua bước Test trên trình duyệt: Tin rằng "AI báo xong nghĩa là code chạy được" mà không tự mình bấm thử các nút trên màn hình.
